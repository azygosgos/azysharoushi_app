# 社労士試験 学習アプリ (sharoushi_app)

社会保険労務士試験の学習を、スキマ時間に効率よく進めるための個人学習用アプリです。
「過去問 → 出題論点 → 根拠法令 → 解説 → 復習」を1つにつなげ、間隔反復(忘却曲線)による復習を行います。

このREADMEは、プログラミング初心者の方でも迷わず動かせるように書いています。
専門用語には簡単な説明を添えています。

---

## 1. このアプリの概要

- 個人利用専用の学習アプリです(ログイン機能・サーバーはありません)。
- **PWA(Progressive Web App)** として作られています。ブラウザ上で動きますが、
  iPhoneのSafariから「ホーム画面に追加」すると、アプリのように使えます。
- データはすべて**あなたの端末の中だけ**に保存されます(オフラインでも使えます)。
- Windows PC・Mac・iPhoneのブラウザで同じように動きます。

**現在のステータス: Phase 1(最初のバージョン)**
労働基準法のオリジナル確認問題のみで、以下が動作する状態です。
- 問題に回答する / 正誤判定 / 解説を見る
- 回答履歴が保存される(アプリを閉じても消えない)
- 間違えた問題が自動的に「復習対象」になる
- 問題ごとにメモを保存できる
- 「今日の復習」画面で、復習すべき問題を確認できる

## 2. 使用している技術

| 技術 | 説明 |
|---|---|
| Flutter / Dart | 1つのコードでWeb・iPhone・PC等に対応できる開発フレームワーク・プログラミング言語 |
| Flutter Web | Flutterアプリをブラウザで動かす仕組み |
| Riverpod (flutter_riverpod) | 画面の状態管理(データが変わったら画面を更新する仕組み)のためのライブラリ |
| Hive (hive_ce / hive_ce_flutter) | 端末内にデータを保存するローカルデータベース。Web版ではブラウザのIndexedDB(内部データ保存領域)を自動的に使う |
| PWA | ブラウザアプリをスマホアプリのように使えるようにする技術。Service Worker(バックグラウンドで通信・保存を管理する仕組み)によりオフライン動作を実現 |

**あえて使っていない技術**: コード自動生成ツール(build_runner等)。
初心者が原因を追いにくくなるため、Phase1ではすべて手書きのコードにしています。

## 3. フォルダ構成

```
sharoushi_app/
├── lib/                       # アプリ本体のDartコード
│   ├── main.dart              # 起動処理(Hiveの初期化など)
│   ├── app.dart                # アプリ全体の設定(テーマ・最初の画面)
│   ├── models/                  # データの入れ物(Subject, Question, Attempt など)
│   ├── repositories/           # データの保存・取得を担当する層(Hiveとのやりとりはここだけ)
│   ├── services/                # ロジック担当(復習間隔の計算、データ読み込み等)
│   ├── providers/               # Riverpodの状態管理定義
│   ├── screens/                  # 画面ごとのUI
│   ├── widgets/                  # 画面で使い回す小さな部品
│   └── constants/                # Hiveのボックス名などの定数
├── assets/data/                # 教材データ(JSON)。ここを編集すれば問題を追加できる
│   ├── subjects.json            # 科目
│   ├── topics.json              # 出題論点
│   ├── laws.json                # 法律
│   ├── articles.json            # 条文
│   ├── questions.json           # 問題(最重要ファイル)
│   ├── daily_tips.json          # 今日のワンポイント
│   └── sources.json             # データの出典
├── web/                         # PWA設定(アイコン・manifest.json等)
├── test/                        # 自動テスト
├── pubspec.yaml                 # 使用パッケージの一覧
└── README.md                    # このファイル
```

**設計のポイント**: `models`(データの形) → `repositories`(保存・取得) → `services`(ロジック)
→ `providers`(状態管理) → `screens`(画面) という順に依存する構造にしています。
「保存方法を変えたい」ときは`repositories`だけ、「画面デザインを変えたい」ときは`screens`だけを
触ればよいように分離しています。

## 4. 初回セットアップ・動作確認(まずはこれを実行してください)

このプロジェクトは、AI(Claude)がこのフォルダに直接コードを書き込んで作成しました。
Claudeはこの環境の制約上、`flutter`コマンド自体を実行して動作確認することができなかったため、
**下記の手順をあなたのPCで実行して、結果を教えてください。**
エラーが出た場合は、そのエラーメッセージをそのままAIに伝えていただければ、コードを修正します。

### 4-1. PowerShell(パワーシェル)とは

Windowsに最初から入っている、文字を打ち込んでコンピューターに指示を出すための画面(アプリ)です。
普段マウスでクリックしている操作を、キーボードで文字を打って行うイメージです。
特別なインストールは不要です。

### 4-2. PowerShellを開く手順

1. キーボードの **Windowsキー**(旗のマーク、キーボード左下あたり)を押します。
   または、画面左下の **Windowsマーク(スタートボタン)** をマウスでクリックします。
2. そのまま `PowerShell` とキーボードで入力します(検索ボックスが自動的に出てきます)。
3. 検索結果に表示される **「Windows PowerShell」**(青い画面のようなアイコン)をクリックします。
4. 濃い青(または黒)の背景に文字が表示されたウィンドウが開きます。これがPowerShellです。
   `PS C:\Users\あなたの名前>` のような表示の右側に、文字を入力できる状態になっています。

### 4-3. コマンドを実行する手順

以下、1行ずつ順番に行います。

1. 下記の1行目 `cd development\sharoushi_app` をコピーします
   (マウスで文字を選択 → 右クリック →「コピー」)。
2. PowerShellの画面をクリックしてから、右クリックすると貼り付けられます
   (貼り付け後、自動で実行はされません)。
3. キーボードの **Enterキー** を押すと、そのコマンドが実行されます。
4. 文字がいくつか表示されて、また `PS C:\...\sharoushi_app>` のような表示に戻ったら、
   そのコマンドは終わりです。次のコマンドをコピー&貼り付け→Enter、で進めます。
5. これを4つのコマンドすべてで繰り返します。

```powershell
cd development\sharoushi_app

# 1. 使用パッケージをダウンロードする(初回・pubspec.yaml変更時に必要。少し時間がかかることがあります)
flutter pub get

# 2. コードに重大な問題がないかチェックする
flutter analyze

# 3. 自動テストを実行する
flutter test

# 4. Chromeで実際に動かしてみる(実行するとChromeが自動で開きます)
flutter run -d chrome
```

- `flutter run -d chrome` を実行すると、しばらく待った後にChromeが自動的に開いて、
  アプリの画面(ホーム画面)が表示されるはずです。これが表示されれば成功です。
- アプリを終了したいときは、PowerShellの画面をクリックしてから `q` キーを押します。

### 4-4. エラーが出たときは

- 赤い文字でメッセージがたくさん表示された場合はエラーです。壊れているわけではないので大丈夫です。
- そのエラーメッセージ全体を、マウスでドラッグして選択し、右クリック(またはEnterキー)でコピーします。
  (PowerShellでは、範囲選択してEnterキーを押すだけでコピーできる場合もあります)
- コピーした内容を、そのままAIとのチャットに貼り付けて送ってください。原因を調べて修正します。

すべて成功すれば、Phase1は完成です。

## 8. 問題データの追加方法

1. `assets/data/questions.json` を開きます。
2. 既存の問題(`{ "id": "q001", ... }` のかたまり)をコピーして、末尾に貼り付けます。
3. `id` は他の問題と重複しないユニークな値にします(例: `q018`)。
4. 各項目を書き換えます。

```jsonc
{
  "id": "q018",
  "subjectId": "sub_roudoukijunhou",   // 科目ID(subjects.jsonのidと合わせる)
  "year": null,                          // 出題年度(オリジナル問題ならnull)
  "questionNumber": null,
  "questionType": "trueFalse",          // "trueFalse"(○×) / "fiveChoice"(5肢択一)
  "questionText": "問題文をここに書きます。",
  "correctAnswer": "true",              // ○×問題なら "true" か "false"
  "explanation": "オリジナルの解説文。",
  "learningPoint": "試験対策上のポイント。",
  "commonTrap": "間違えやすいポイント。",
  "legalBasis": "労働基準法第◯条",
  "relatedArticleIds": ["art_35"],      // articles.jsonのidを指定(任意)
  "importance": "a",                     // "s" / "a" / "b" / "c"
  "topicId": "t_kyujitsu",              // topics.jsonのid(任意)
  "sourceId": "src_original"
}
```

5. **重要**: `lib/services/data_loader_service.dart` を開き、
   `currentDataVersion` の数字を1つ増やします(例: `1` → `2`)。
   これを忘れると、次回起動時に新しい問題が反映されません。
6. `flutter run -d chrome` (または再ビルド)して確認します。

5肢択一問題を追加する場合は、`questionType`を`"fiveChoice"`にし、
`choices`に選択肢の配列(`{"id": "A", "text": "選択肢の文章"}`など)を追加、
`correctAnswer`には正解の選択肢の`id`(例: `"A"`)を指定してください。

## 9. 解説の追加方法

解説は問題データ(`questions.json`)の中の以下の項目に対応しています。

- `explanation`: オリジナル解説(条文や公的資料を根拠に、自分の言葉で書く)
- `learningPoint`: 試験対策上のポイント
- `commonTrap`: 間違えやすいポイント
- `legalBasis`: 根拠法令(表示用テキスト)

**著作権に関する注意**: 市販の参考書・問題集の文章をそのまま転記しないでください。
条文(法令)や厚生労働省等の公的資料を根拠に、必ず自分の言葉で解説を作成してください。

## 10. 法令データの追加方法

1. `assets/data/laws.json` に法律を追加(例: 労働安全衛生法)。
2. `assets/data/articles.json` に条文を追加します。

```jsonc
{
  "id": "art_XX",
  "lawId": "law_roudoukijunhou",
  "chapterTitle": "第◯章 ◯◯◯◯",
  "articleNumber": "第XX条",
  "title": "条文の見出し",
  "paragraphs": ["第1項の条文テキスト", "第2項の条文テキスト"],
  "examPoints": ["試験でよく問われるポイント"]
}
```

条文は必ず [e-Gov法令検索](https://laws.e-gov.go.jp/) 等、公的機関が公開している一次情報を
根拠にしてください。`data_loader_service.dart`の`currentDataVersion`を増やすのを忘れずに。

## 11. バックアップ方法

学習履歴・復習予定・メモ・お気に入りをバックアップする仕組みは、
`lib/services/backup_service.dart` にロジックとして用意済みです。

**Phase1時点では、画面にボタンはまだ設置していません**(Phase2以降で追加予定です)。
データ構造(データベースの設計)はすでにこの機能に対応できる形になっているので、
将来「バックアップを作成」「バックアップから復元」ボタンを追加するだけで使えるようになります。

## 12. よくあるエラーへの対処

| エラー・症状 | 原因と対処 |
|---|---|
| `flutter pub get` で赤いエラーが出る | パッケージのバージョンが噛み合っていない可能性があります。エラーメッセージ全体をAIに伝えてください。 |
| `flutter analyze` で `unused_import` 等が出る | 重大なエラーではありません(使っていないimport文の警告)。気になる場合はAIに伝えれば削除します。 |
| Chromeで真っ白な画面のまま | 開発者ツール(F12)のConsoleタブにエラーが出ていないか確認してください。 |
| 問題を追加したのに表示されない | `data_loader_service.dart` の `currentDataVersion` を増やし忘れている可能性が高いです。 |
| データがおかしくなった/リセットしたい | ブラウザの開発者ツール →「Application」→「Storage」→「Clear site data」でリセットできます(学習履歴も消えるので注意)。 |
| `flutter: command not found` | Flutter SDKの場所(`development\flutter\bin`)にPATHが通っていない可能性があります。 |
